# Vue Report UI - Portfolio Preview

Standalone browser demo of a **Vue.js 2** reporting interface.  
Adapted from a commercial FiveM NUI product - **source code is private**.

**Stack:** Vue 2.7 (Options API) · JavaScript · Vite · CSS

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). No FiveM required.

## Screens

- Category selector (Player / Bug / Question)
- Report form with validation and mock upload
- Admin list (search, sort) and report detail

Use **Player view / Admin view** or the **Jump to** bar to switch screens.

## Note

This repo is a **public demo only**. Lua backends, configs, webhooks, and proprietary assets are not included.
